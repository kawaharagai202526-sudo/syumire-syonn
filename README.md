## dance3d — ダンス動画から「1人だけ」の動きを3Dアニメにする

グループのダンス動画から **金髪の人物だけ** を自動で見つけ、その人の動きを3Dの人形で再現した、
見やすい練習用の動画を作ります。

### 完成した動画

`output/` フォルダにあります（元動画の映像・音声は含みません）。

| ファイル | 内容 |
|---|---|
| `output/dance3d.mp4` | 通常速度（1080p） |
| `output/dance3d_slow.mp4` | 0.5倍速（1080p） |

### 画面の見方

| 画面 | 内容 |
|---|---|
| 左（大） | 3Dビュー（斜め前から）。カメラが人物をゆっくり追いかける。手首・足首の軌跡つき |
| 右上 | 正面（元の動画と同じ向き） |
| 右下 | 背面（自分と同じ向き）。左右が自分の手足と一致するので真似しやすい |
| 左下 | 立ち位置マップ（真上から見た移動の軌跡と体の向き。下が客席・カメラ側） |

- 本人の **左腕・左脚 = 青**、**右腕・右脚 = オレンジ**
- 頭は金髪＋顔（目）つきなので、顔の向きが一目でわかる
- 胴体は胸側が明るく、背中側が暗い。床の金色の矢印は体の向き
- 他のメンバーに隠れて推定できない瞬間は、人形が灰色になる

### 仕組み

1. **全員を検出**: YOLOX（ONNX）で毎フレーム全員の人物枠を検出。数フレームごとに各人の切り抜きで
   MediaPipe Pose を動かし、頭と胴体の位置を取る
2. **金髪の人を特定**: 頭部を MediaPipe Hair Segmenter で髪だけ切り出し、髪の明るさ・黄色みを比較。
   服の色と位置の連続性も使ってトラック同士をつなぎ、隠れたり交差したりしても同じ人を追い続ける
3. **その人だけ高精度に再推定**: 対象の周りを切り抜き（他の人の枠は灰色で塗りつぶし）、
   MediaPipe Pose（heavy）で毎フレーム推定。YOLOX の枠と一致する人だけを採用
4. **カメラ補正**: 撮影者のズーム・パンを背景の特徴点（KLT＋SIFT）から推定して打ち消す。
   明るい照明と暗い照明の区間それぞれに基準フレームを置き、切り替わりでつなぐ
5. **3D化**: 左右の取り違え補正・一瞬の誤検出の除去・欠損補間・平滑化・骨の長さを一定に。
   2Dと3Dの対応からカメラからの距離を推定してステージ上の移動も再現。床の傾きも補正
6. **描画**: OpenCV で影・床グリッド・軌跡つきの3D人形をレンダリング

### 使い方

```bash
pip install -r dance3d/requirements.txt
./dance3d/run.sh input/video.mp4 output
```

- `output/dance3d.mp4` … 通常速度
- `output/dance3d_slow.mp4` … 0.5倍速
- `output/check_target.mp4` … どの人を対象にしたかの確認用（元動画に枠を重ねたもの・コミットしない）

自動判定が別の人を選んだ場合は、時刻と画面上の位置（0〜1）で指定できます:

```bash
./dance3d/run.sh input/video.mp4 output --hint 12.0,0.45,0.5
```

動画の最後に終了画面などが入っている場合は `--max-frames`（解析するフレーム数）で切り落とします。
